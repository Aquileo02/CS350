# CS350

This project focused on building a Raspberry Pi thermostat system that used sensors, LEDs, and an LCD display to monitor temperature and control system states. The goal of the project was to create interface software that allowed hardware components to communicate with each other and display useful information to the user. This project helped demonstrate how software and hardware work together in an embedded system environment.

One thing I did particularly well in this project was troubleshooting wiring and programming issues step by step. When something did not work correctly, I checked connections carefully and reviewed my code to find errors. This helped me understand how important testing each part of a system is before combining everything together.

One area where I could improve is planning the layout of my circuit earlier before building it. Sometimes I had to reorganize wiring after starting the project, and better planning would have saved time. I would also like to improve my confidence working with hardware components and debugging them more quickly.

Some tools and resources I added to my support network during this project include the Raspberry Pi documentation, GPIO pinout charts, course materials, and online troubleshooting guides. These resources helped me solve problems and better understand how the components worked together.

Skills from this project that will transfer to future coursework include working with sensors, using GPIO pins, writing interface software, troubleshooting hardware connections, and understanding how embedded systems communicate. These skills are useful for future projects that involve hardware and software integration.

To make this project maintainable and readable, I organized my code into sections and added comments explaining what each part of the program does. I also tested individual components before combining them into the final system. This made the project easier to debug and adjust if changes were needed later.
